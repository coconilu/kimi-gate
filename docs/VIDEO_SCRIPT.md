# B 站演示视频 · 分镜脚本

> 目标：2~3 分钟，让观众看完就知道"kimi-gate 是什么、安不安全、怎么 30 秒开始"。
> 风格：实拍实录（真机真服务器），不剪花哨特效，节奏紧凑。
> 发布标题建议：《出门也能用手机写代码？我把 Kimi Code 装进了口袋｜开源自托管》

## 拍摄前准备

- [ ] 一台手机（鸿蒙/任意）+ 家里电脑 + 已部署好的 kimi-gate
- [ ] **脱敏检查**：管理台密码、配对密钥、服务器 IP 不入镜；管理台"Connector 接入"区块的密钥部分后期打码或截屏时遮挡
- [ ] 手机录屏开启（鸿蒙：控制中心 → 屏幕录制）；电脑端用 OBS 录终端和浏览器
- [ ] 提前把家里电脑的 connector 停掉，模拟"从零接入"
